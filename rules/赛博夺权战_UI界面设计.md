# 赛博夺权战 — UI界面设计文档

## 一、架构总览

```
┌─────────────────────────────────────────────────────────┐
│                    Manager进程 (Python)                  │
│                                                          │
│  ┌─────────────────┐    ┌─────────────────────────────┐ │
│  │   System模块     │    │      控制面板 (PySide6)      │ │
│  │  (同进程)        │    │  - 专业工具型布局             │ │
│  └─────────────────┘    │  - 完整控制权限               │ │
│         ↑               │  - 人工介入弹窗               │ │
│    直接函数调用         │  - 裁判AI推理可视化           │ │
│         │               │  - 网络通信指标               │ │
│  ┌─────────────────┐    └─────────────────────────────┘ │
│  │   Manager核心    │              ↑                    │
│  │  (调度/积分/裁判)│         原生集成                   │
│  └─────────────────┘              │                    │
│         │                         │                    │
│         ↓ 状态序列化              │                    │
│  ┌─────────────────┐              │                    │
│  │   录像/回放引擎   │              │                    │
│  │  (JSON状态序列)   │              │                    │
│  └─────────────────┘              │                    │
│         │                         │                    │
│         ↓ HTTP推送                │                    │
│  ┌─────────────────────────────────────────────────────┐│
│  │            Web观战面板 (浏览器)                       ││
│  │  - 观战大屏型布局                                    ││
│  │  - 只读，无控制权限                                   ││
│  │  - 支持AI视角切换                                    ││
│  │  - 实时/回放模式                                     ││
│  └─────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────┘
```

| 组件 | 技术 | 权限 | 目标用户 |
|------|------|------|----------|
| 控制面板 | PySide6原生集成 | 完整控制 | 裁判/管理员 |
| Web观战面板 | HTTP推送+前端渲染 | 只读观战 | 观众/选手 |

## 二、控制面板 (PySide6)

### 2.1 整体布局

```
┌─────────────────────────────────────────────────────────┐
│  菜单栏  [文件] [视图] [控制] [调试] [帮助]              │  ← 顶部功能菜单
├─────────────────────────────────────────────────────────┤
│  工具栏  [▶/⏸] [⏹] [⏪] [⏩] [×1 ▼] [介入] [导出]      │  ← 快捷控制
├──────────┬──────────────────────────────┬───────────────┤
│          │                              │               │
│  左侧    │         中央主区域            │    右侧      │
│  导航    │                              │    详情      │
│  面板    │   ┌──────────────────────┐   │    面板      │
│          │   │   系统状态仪表盘      │   │               │
│  - 比赛  │   │   (健康度/owner/状态) │   │  - 积分排行  │
│  - AI    │   └──────────────────────┘   │  - 网络指标  │
│  - 文件  │   ┌──────────────────────┐   │  - 裁判队列  │
│  - 日志  │   │   终端日志流          │   │               │
│  - 裁判  │   │   (黑底绿字，可筛选)   │   │               │
│          │   └──────────────────────┘   │               │
│          │                              │               │
├──────────┴──────────────────────────────┴───────────────┤
│  底部状态栏  [T+14:32] [NORMAL] [AI_1 owner] [⚡ 60fps] │
└─────────────────────────────────────────────────────────┘
```

### 2.2 顶部菜单栏

| 菜单 | 功能 |
|------|------|
| **文件** | 新建比赛 / 加载配置 / 导出JSON录像 / 退出 |
| **视图** | 切换面板布局 / 主题深浅 / 全屏 |
| **控制** | 暂停/继续 / 加速(×1/×2/×4/×8) / 强制加时 / 终止比赛 |
| **调试** | 显示网络指标 / 显示裁判推理 / 模拟AI延迟 |
| **帮助** | 规则文档 / 快捷键 / 关于 |

### 2.3 工具栏

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| ▶/⏸ | 暂停/继续 | Space |
| ⏹ | 终止比赛 | Ctrl+T |
| ⏪ | 回退10秒 | ← |
| ⏩ | 前进10秒 | → |
| ×1 ▼ | 播放速度下拉 | 1/2/3/4 |
| 介入 | 弹出人工介入框 | Ctrl+I |
| 导出 | 导出当前JSON录像 | Ctrl+E |

## 六、数据流

### 6.1 实时数据流

```
Manager状态变更
    ↓
序列化为JSON帧
    ↓
├─→ 控制面板 (直接函数调用，零延迟)
│
└─→ Web观战面板 (HTTP推送，有延迟)
    ↓
前端解析并渲染
```

### 6.2 录像数据流

```
比赛进行中
    ↓
Manager定时序列化状态到内存缓冲区
    ↓
比赛结束
    ↓
导出为JSON Lines文件 (*.ndjson)
    ↓
回放时逐帧读取，渲染到控制面板或Web面板
```

**录像格式：**
```json
{"t": 0, "type": "snapshot", "state": {...}}
{"t": 100, "type": "event", "event": "owner_change", "data": {...}}
{"t": 200, "type": "frame", "state": {...}}
```

## 八、部署

### 8.1 控制面板

```bash
pip install PySide6
python manager.py  # 内置GUI自动启动
```

### 8.2 Web观战面板

```bash
# Manager启动时自动开启HTTP推送端口
python manager.py --watch-port 8080

# 观众浏览器访问
http://manager-ip:8080/watch
```

### 8.3 多比赛支持

不支持单实例多比赛。多开方式：
- 软件多开：启动多个Manager进程，不同端口
- 浏览器多标签：访问不同端口
